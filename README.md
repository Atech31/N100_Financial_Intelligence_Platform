# N100 Financial Intelligence Platform

Live App: [https://n100atech31.streamlit.app](https://n100atech31.streamlit.app)

## Project Overview
An interactive financial analytics web application designed to evaluate and screen 92 top-performing companies using key financial health metrics, return ratios, and sector distributions.

## Core Capabilities
* **Screener & Universe Metrics**: Macro-level market summary tracking median health scores, debt-free company counts, and customizable multi-sector filtering with dynamic ROE threshold sliders.
* **Company Deep Dive**: Granular single-entity performance analysis detailing company-specific health bands and financial metrics.
* **Sector Intelligence**: Comparative analytics across major market sectors to identify risk exposure and growth trends.

## Tech Stack
* **Language**: Python
* **Data Processing**: Pandas
* **UI & Deployment**: Streamlit / Streamlit Community Cloud
